# java-racingcar-precourse
## 기능 목록

### 사용자 입력 받기
- 경주할 **자동차 이름**을 입력받는다.
    - 자동차 이름은 쉼표(`,`)로 구분한다.
    - 각 이름은 **5자 이하**만 가능하다.
    - 형식이 올바르지 않을 경우 `IllegalArgumentException`을 발생시키고 프로그램을 종료한다.
- **이동 횟수**를 입력받는다.
    - 이동 횟수는 숫자여야 한다.
    - 잘못된 값이 들어올 경우 `IllegalArgumentException`을 발생시키고 프로그램을 종료한다.

### 자동차 경주하기
- 각 자동차는 한 번의 시도에서 **전진하거나 멈출 수 있다.**
- 전진 조건: `0`에서 `9` 사이의 무작위 수를 구해 **4 이상이면 전진**한다.
- 매 시도마다 전진한 자동차의 이름과 이동 상태를 출력한다.
- 지정된 횟수만큼 모든 자동차의 이동을 반복한다.

### 우승자 산출하기
- 모든 이동이 끝난 후, 가장 많이 전진한 자동차를 **우승자**로 결정한다.
- **공동 우승자**가 있을 경우 쉼표(`,`)로 구분하여 출력한다.
- 경주 결과와 함께 우승자를 출력한다.

### 예외 처리
- 이름 길이, 입력 형식, 이동 횟수 등이 유효하지 않을 경우 → `IllegalArgumentException` 발생 후 프로그램 종료.
